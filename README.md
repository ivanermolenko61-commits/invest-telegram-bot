# 📈 Invest Telegram Bot

Telegram-бот — инвестиционный помощник. Читает портфель напрямую из **Tinkoff Invest API** и даёт рекомендации по покупкам на основе целевой структуры.

Работает **24/7 на сервере**, каждый день в 19:00 присылает вечерний отчёт.

---

## 🎯 Возможности

### 📊 Портфель
Топ-10 позиций с ценами и стоимостью, распределение по категориям.

### ⚖️ Структура
Категории со светофором (🟢 🟡 🔴) — видно, что отстаёт от цели:

- **Акции** — 70%
- **Облигации** — 15%
- **Золото** — 10%
- **Валюта** — 5%

Плюс разбивка акций по 9 отраслям с процентами.

### 🎯 Что купить
Главная функция — **план покупок** на указанную сумму:

- 🎯 Приоритет: **Валюта → Золото → Облигации → Акции**
- 🔄 Волновой алгоритм: покупаем самую отстающую отрасль, внутри неё — самую отстающую компанию
- 📉 Не обгоняем следующую отрасль — сохраняем баланс
- 🧮 Учитываем **лоты** (Интер РАО = 100 шт, Сбер = 1 шт)
- 📜 Для облигаций — выбираем **лучшую ОФЗ со всей биржи по YTM**
- 💰 Финальный проход — добираем остаток бюджета

**Пример:**

    📋 План покупок на 15 000 ₽

    💵 Валюта (350 ₽)
       • Китайский юань (CNYRUB_TOM_CETS)
         28 шт × 12.50 ₽ = 350 ₽

    🥇 Золото (775 ₽)
       • Альфа-Капитал Золото (AKGD)
         3 шт × 258.41 ₽ = 775 ₽

    📜 Облигации (2 235 ₽)
       • ОФЗ 26233 (SU26233RMFS5)
         4 шт × 558.66 ₽ = 2 235 ₽
         YTM 19.85% · до 2035-07-18

    📈 Акции (11 636 ₽)

       💻 IT (3 673 ₽) · 8.1% → 11.0%
          • ASTR — Группа Астра
            8 шт × 218.80 ₽ = 1 750 ₽
          • CNRU — Циан
            3 шт × 640.80 ₽ = 1 922 ₽
       ...

    💰 Итого: 14 995.69 ₽ из 15 000.00 ₽
    💵 Остаток: 4.31 ₽

### 🌙 Вечерний отчёт
Каждый день в **19:00 МСК** бот сам присылает портфель и структуру.

### Модули

**`tinkoff_api.py`** — работает с T-Invest API:

- `get_portfolio_snapshot()` — снимок портфеля (позиции, категории, отрасли)
- `get_share_info(tickers)` — информация о бумагах, которых нет в портфеле
- `get_top_ofz(limit)` — топ-ОФЗ по YTM со всей биржи (с кэшем 1 час)

**`recommender.py`** — расчёт плана покупок:

- `recommend_currency()` — добор валюты до 5%
- `recommend_gold()` — добор AKGD до 10%
- `recommend_bonds()` — лучшая ОФЗ по YTM до 15%
- `recommend_stocks()` — волновой алгоритм по отраслям до 70%

**`bot.py`** — Telegram-интерфейс:

- Команды и кнопки
- Форматирование сообщений (HTML)
- Планировщик APScheduler для ежедневного отчёта

## 🚀 Установка

### 1. Клонировать репозиторий

    git clone https://github.com/ivanermolenko61-commits/invest-telegram-bot.git
    cd invest-telegram-bot

### 2. Виртуальное окружение

    python -m venv .venv
    source .venv/Scripts/activate    # Windows Git Bash
    # source .venv/bin/activate      # Linux / macOS

### 3. Зависимости

    pip install -r requirements.txt

### 4. Получить токены

- **BOT_TOKEN** — у [@BotFather](https://t.me/BotFather): `/newbot`
- **TINKOFF_TOKEN** — в приложении Т-Инвестиции: Настройки → Токены для API
- **MY_CHAT_ID** — у [@userinfobot](https://t.me/userinfobot)

### 5. Создать `.env`

    BOT_TOKEN=ваш_токен
    TINKOFF_TOKEN=ваш_токен
    MY_CHAT_ID=ваш_id

### 6. Запустить

    python bot.py

## 📊 Как работает подбор акций

**Целевая структура:** 70% акции, 15% облигации, 10% золото, 5% валюта.

**Внутри акций** — 9 отраслей, целевая доля каждой = 100% / 9 ≈ 11.11%.

**Алгоритм:**

1. Считаем текущие доли отраслей
2. Берём **3 самые отстающие**
3. В каждой находим **самую отстающую компанию**
4. Считаем лимит — не обогнать следующую отрасль
5. Покупаем **N лотов** (N = min(разрыв, лимит, бюджет) / цена_лота)
6. Если в отрасль не влезает — идём к следующей
7. **Волнами** — после каждой покупки пересчитываем

**Пример волны:**

    IT → Сырьевая → IT → Телеком → IT → ... → бюджет исчерпан

**Тай-брейк** при равных долях — по алфавиту (ASTR всегда раньше CNRU).

## 📜 Как выбирается ОФЗ

Вместо «самой дешёвой из портфеля» — **самая доходная со всей биржи**.

1. Получаем все ОФЗ (~57 штук)
2. Фильтруем: срок ≥ 1 год, есть купон, цена валидна
3. Считаем **YTM** для каждой:

       YTM = (годовой_купон + (номинал − цена) / лет_до_погашения) / цена × 100%

4. Сортируем по убыванию, берём топ-3
5. В рекомендацию идёт топ-1

**Кэш:** результат хранится 1 час в памяти — не бьём API на каждом запросе.

**Пример:**

    ОФЗ 26233 (SU26233RMFS5)
    559 ₽ · купон 61 ₽/год · до 2035-07-18 · YTM 19.83%
