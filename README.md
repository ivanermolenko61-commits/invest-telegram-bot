# 📈 Invest Telegram Bot

Telegram-бот — инвестиционный помощник. Читает портфель напрямую из **Tinkoff Invest API**, даёт рекомендации по покупкам и AI-анализ через **YandexGPT**.

Работает **24/7 на сервере**, каждый день в 19:00 присылает вечерний отчёт.

---

## 🎯 Возможности

### 📊 Портфель
Топ-10 позиций с ценами и стоимостью, распределение по категориям.

### ⚖️ Структура
Категории со светофором (🟢 🟡 🔴) — видно, что отстаёт от цели:

- **Акции** — 70%
- **Облигации** — 15%
- **Золото** — 10%
- **Валюта** — 5%

Плюс разбивка акций по 9 отраслям с процентами.

### 🎯 Что купить
Главная функция — **план покупок** на указанную сумму:

- 🎯 Приоритет: **Валюта → Золото → Облигации → Акции**
- 💵 Валюта: баланс USD ↔ CNY (по 2.5% на каждую)
- 🥇 Золото: один фонд AKGD, без диверсификации
- 📜 Облигации: **лучшая ОФЗ со всей биржи по YTM**
- 🔄 Акции: волновой алгоритм — покупаем самую отстающую отрасль
- 🧮 Учитываем **лоты** (Интер РАО = 100 шт, Сбер = 1 шт)
- 💰 Финальный проход — добираем остаток бюджета

**Пример:**

    📋 План покупок на 15 000 ₽

    💵 Валюта (364 ₽)
       • Китайский юань (CNYRUB_TOM_CETS)
         29 шт × 12.57 ₽ = 364 ₽

    🥇 Золото (780 ₽)
       • Альфа-Капитал Золото (AKGD)
         3 шт × 260.26 ₽ = 780 ₽

    📜 Облигации (2 230 ₽)
       • ОФЗ 26233 (SU26233RMFS5)
         4 шт × 557.38 ₽ = 2 230 ₽
         YTM 19.92% · до 2035-07-18

    📈 Акции (11 562 ₽)

       💻 IT (1 746 ₽) · 8.1% → 10.8%
          • ASTR — Группа Астра
            8 шт × 218.50 ₽ = 1 748 ₽
       ...

    💰 Итого: 14 936 ₽ из 15 000 ₽
    💵 Остаток: 64 ₽

### 🤖 AI-анализ
Команда `/analyze` — анализ портфеля от **YandexGPT**:

- Проверка отклонений от целевых долей
- Оценка концентрации в отдельных акциях
- Проверка равномерности по отраслям
- Общая оценка диверсификации

**Пример:**

    🤖 Анализ портфеля

    Ваш портфель хорошо сбалансирован, однако есть небольшие
    отклонения от целевых долей: доля акций чуть ниже целевого
    значения, а доля золота и валюты немного выше.

    Концентрация в отдельных акциях некритична. Распределение
    по отраслям достаточно равномерное, что способствует
    диверсификации рисков. Однако телекоммуникации и энергетика
    имеют более высокую долю, чем другие.

### 🌙 Вечерний отчёт
Каждый день в **19:00 МСК** бот сам присылает портфель и структуру.

### Модули

**`tinkoff_api.py`** — работает с T-Invest API:

- `get_portfolio_snapshot()` — снимок портфеля (позиции, категории, отрасли)
- `get_share_info(tickers)` — информация о бумагах из wishlist
- `get_top_ofz(limit)` — топ-ОФЗ по YTM со всей биржи (кэш 30 мин)

**Автоклассификация бумаг:**
- Портфельные бумаги матчатся **по figi** в справочнике API
- Сектор берётся из поля `sector` (маппинг в `SECTOR_FROM_API`)
- Названия и лоты — **из API**, без хардкода
- Любая новая бумага (OZON, TATN) подхватывается автоматически

**`recommender.py`** — расчёт плана покупок:

- `recommend_currency()` — баланс USD ↔ CNY по 2.5%
- `recommend_gold()` — добор AKGD до 10%
- `recommend_bonds()` — лучшая ОФЗ по YTM до 15%
- `recommend_stocks()` — волновой алгоритм по отраслям до 70%

**`ai_advisor.py`** — AI-анализ:

- `analyze_portfolio(snapshot)` — отправляет данные в YandexGPT
- `is_enabled()` — проверяет, что ключи настроены

**`bot.py`** — Telegram-интерфейс:

- Команды и кнопки
- Форматирование сообщений (HTML)
- Планировщик APScheduler для ежедневного отчёта

## 🚀 Установка

### 1. Клонировать репозиторий

    git clone https://github.com/ivanermolenko61-commits/invest-telegram-bot.git
    cd invest-telegram-bot

### 2. Виртуальное окружение

    python -m venv .venv
    source .venv/Scripts/activate    # Windows Git Bash
    # source .venv/bin/activate      # Linux / macOS

### 3. Зависимости

    pip install -r requirements.txt

### 4. Получить токены

- **BOT_TOKEN** — у [@BotFather](https://t.me/BotFather): `/newbot`
- **TINKOFF_TOKEN** — в приложении Т-Инвестиции: Настройки → Токены для API
- **MY_CHAT_ID** — у [@userinfobot](https://t.me/userinfobot)
- **YANDEX_API_KEY** и **YANDEX_FOLDER_ID** — в Yandex Cloud (см. ниже)

### 5. Создать `.env`

    BOT_TOKEN=ваш_токен
    TINKOFF_TOKEN=ваш_токен
    MY_CHAT_ID=ваш_id
    YANDEX_API_KEY=ваш_ключ
    YANDEX_FOLDER_ID=ваш_folder_id

### 6. Запустить

    python bot.py

## 🤖 Настройка YandexGPT

Для работы `/analyze` нужен API-ключ Yandex Cloud.

### 1. Войдите в [Yandex Cloud Console](https://console.yandex.cloud/)

### 2. Создайте платёжный аккаунт
- Раздел **Billing** → активируйте платную версию
- Привяжите карту
- Грант 4 000 ₽ на 60 дней обычно выдаётся автоматически

### 3. Создайте каталог (или используйте `default`)
- Скопируйте **ID каталога** (`b1g...`) — это `YANDEX_FOLDER_ID`

### 4. Создайте сервисный аккаунт
- **IAM** → **Сервисные аккаунты** → Создать
- Имя: `gpt-bot-sa`
- **Роль:** `ai.languageModels.user`

### 5. Создайте API-ключ
- На странице сервисного аккаунта → **API-ключи** → Создать
- **⚠️ Скопируйте сразу** — показывается один раз
- Это ваш `YANDEX_API_KEY`

### Стоимость

YandexGPT Lite: **0,20 ₽ за 1000 токенов**.

- Один `/analyze` ≈ 1800 токенов = **0,0004 ₽**
- **Бесплатный лимит** — 10 млн токенов/мес = ~5500 запросов
- Гранта 4 000 ₽ хватит на **~11 000 запросов**

Для личного использования — фактически бесплатно.

## 📊 Как работает подбор акций

**Целевая структура:** 70% акции, 15% облигации, 10% золото, 5% валюта.

**Внутри акций** — 9 отраслей, целевая доля каждой = 100% / 9 ≈ 11.11%.

**Алгоритм:**

1. Считаем текущие доли отраслей
2. Берём **3 самые отстающие**
3. В каждой находим **самую отстающую компанию**
4. Считаем лимит — не обогнать следующую отрасль
5. Покупаем **N лотов** (N = min(разрыв, лимит, бюджет) / цена_лота)
6. Если в отрасль не влезает — идём к следующей
7. **Волнами** — после каждой покупки пересчитываем

**Пример волны:**

    IT → Сырьевая → IT → Телеком → IT → ... → бюджет исчерпан

**Тай-брейк** при равных долях — по алфавиту (ASTR всегда раньше CNRU).

## 📜 Как выбирается ОФЗ

Вместо «самой дешёвой из портфеля» — **самая доходная со всей биржи**.

1. Получаем все ОФЗ (~57 штук)
2. Фильтруем: срок ≥ 1 год, есть купон, цена валидна
3. Считаем **YTM** для каждой:

       YTM = (годовой_купон + (номинал − цена) / лет_до_погашения) / цена × 100%

4. Сортируем по убыванию, берём топ-3
5. В рекомендацию идёт топ-1

**Кэш:** результат хранится **30 минут** — не бьём API на каждом запросе.

**Пример:**

    ОФЗ 26233 (SU26233RMFS5)
    557 ₽ · купон 122 ₽/год · до 2035-07-18 · YTM 19.92%
